# Vendored fonts

Variable latin subsets served through `next/font/local` from `src/app/layout.tsx`, so production builds never fetch from Google Fonts.

| File | Family | Weights | Source |
| --- | --- | --- | --- |
| `Inter-latin.woff2` | Inter | 100–900 | fonts.gstatic.com (Google Fonts, Inter v20) |
| `SpaceGrotesk-latin.woff2` | Space Grotesk | 300–700 | fonts.gstatic.com (Google Fonts, Space Grotesk v22) |

Both families are licensed under the SIL Open Font License 1.1.
